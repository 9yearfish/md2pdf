准备就绪

在浏览器里把 Markdown 转成 PDF

粘贴或拖入一份 Markdown，点「生成 PDF」，右侧立刻就是排好版的结果。你看到的那一页， 就是点下载后拿到的那个文件 —— 预览和下载是同一份数据，不存在「预览好看、导出错位」。

整个过程没有服务器参与。Markdown 解析、流程图渲染、排版和 PDF 生成全部在这个标签页里完成， 不需要注册，没有水印，也没有次数限制。

流程图是矢量的，不是截图

```mermaid 代码块会被渲染成 SVG 并以原生矢量图形嵌入 PDF。放大到任意倍数都清晰， 图里的文字可以被选中、复制和搜索，classDef 自定义的填充色、描边颜色和线宽都会完整保留。 很多在线工具是把流程图转成位图贴进 PDF 的，放大会糊，文字也选不中。

中文是真文字

中文以可选中、可搜索的真实文本嵌入，字体会自动子集化以控制文件体积。 常用汉字使用一份较小的字体子集，如果文档里出现了子集之外的生僻字，会自动切换到完整字体， 不会出现缺字的方块。中英文混排时会正确处理断行，不会插入多余空格。

排版由真正的排版引擎完成

底层用的是 Typst —— 一个编译成 WebAssembly、可以在浏览器里运行的现代排版系统。 分页、孤行控制、目录、页码、脚注和 PDF 书签都由它处理，代码高亮也由它内置的高亮器完成。 这也意味着首次转换需要下载约 7 MB 的引擎，下载一次之后会缓存在本机，之后可以离线使用。

支持的 Markdown 语法

标题、段落、粗体、斜体、删除线、行内代码、链接、图片、有序与无序列表、嵌套列表、 任务列表、引用块、带对齐的表格、定义列表、脚注、分隔线、围栏代码块（带语法高亮）、 以及 Mermaid 流程图。图片支持拖拽和粘贴本地文件。

常见问题

我的文档会被上传到服务器吗？

不会。站点的内容安全策略不允许向自身以外的任何地址发起网络请求， 所以「不上传」不是一句承诺，而是浏览器强制执行的限制。

为什么首次使用要等一会儿？

页面本身只有几十 KB，打开是即时的。等待的是排版引擎 —— 约 7 MB 的 WebAssembly， 只在第一次转换时下载，并且会显示下载进度。之后它会被缓存下来，再次使用无需等待， 离线也能工作。

支持数学公式吗？

当前版本尚不支持数学公式。

可以用 HTML 标签吗？

除 <br> 外不支持。排版引擎没有与 HTML 对应的语义， 与其渲染出一个似是而非的结果，不如明确跳过并给出提示。
